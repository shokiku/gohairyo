# ごはいりょ — 配布情報

iOS アプリ「ごはいりょ」の公式サイト（GitHub Pages）をホストするリポジトリです。

**公式サイト**: https://shokiku.github.io/gohairyo/

## 内容

- `index.html` — トップページ（アプリ紹介・入手先・サポート案内）
- `privacy/index.html` — プライバシーポリシー（日英併記）
  - 公開URL: https://shokiku.github.io/gohairyo/privacy/
  - App Store の「サポートURL」「プライバシーポリシーURL」にこの配下を使用

## 公開設定

GitHub Pages（`main` ブランチ・ルート `/`）で配信。`/` がトップ、`/privacy/` がポリシー。
